# AI Scooty Assistant (ইংরেজি চ্যাটবট, ওয়েব ভার্সন)

AI Scooty-র জন্য একটি ইন্টারনাল FAQ চ্যাটবট। Python 3.13 + FastAPI, Windows 11 স্টাইলের ওয়েব UI,
এবং Ollama-র ছোট মডেল (Qwen 0.6B)। এই ভার্সনে ডেটাবেস নেই, সব জ্ঞান `data/knowledge.json` ফাইলে থাকে।

---

## ১. কী কী আছে

- হোম পেজের ঠিক মাঝখানে Windows-স্টাইল চ্যাট উইন্ডো, পেছনে AI Scooty-র স্যাম্পল ছবি (সোলার প্যানেলসহ)
- থিম বদলানো যায়: Light / Dark / System এবং ৬টি Accent রং (উইন্ডোর উপরের গিয়ার বাটনে)
- চ্যাট ব্রাউজারে সেভ থাকে, রিফ্রেশ করলেও কথাবার্তা থাকে
- প্রতিটি প্রশ্নের জন্য ৫০+ রকম করে লেখার ধরন (synonym/paraphrase) ডেটাসেটে আছে
- জ্ঞানের বাইরের প্রশ্নে বট উত্তর বানায় না, বরং কাস্টমার সাপোর্টের ফোন নম্বর দেয়
- Ollama বন্ধ থাকলেও বট চলে (তখন লেখা উত্তরই দেখায়)

## ২. যা যা লাগবে

1. **Python 3.13** (https://www.python.org/downloads/) ইনস্টল করার সময় "Add python.exe to PATH" টিক দিন
2. **Ollama** (https://ollama.com/download) ইনস্টল করুন (ছোট মডেল ব্যবহারের জন্য)

## ৩. চালানোর ধাপ (Windows)

1. জিপ ফাইলটা Extract করুন (যেমন `C:\ai-scooty-chatbot`)
2. Command Prompt খুলে একবার এই কমান্ড দিন (মডেল ডাউনলোড হবে):
   ```
   ollama pull qwen3:0.6b
   ```
3. `start.bat` ফাইলে **দুবার ক্লিক** করুন। প্রথমবার নিজে থেকেই সব ইনস্টল করে নেবে।
4. ব্রাউজারে খুলুন: **http://127.0.0.1:8000**

হাতে হাতে চালাতে চাইলে (যেকোনো সিস্টেমে):
```
python -m venv .venv
.venv\Scripts\activate          (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
python tools/build_dataset.py
python run.py
```

PyCharm-এ চালাতে: ফোল্ডারটা Open করুন, interpreter হিসেবে Python 3.13 দিন, `requirements.txt` ইনস্টল করুন, তারপর `run.py` Run করুন।

## ৪. ⚠️ সবচেয়ে জরুরি: সাপোর্টের ফোন নম্বর বসান

এখন নম্বরের জায়গায় `+880-XXXX-XXXXXX` লেখা আছে। আসল নম্বর বসাতে `start.bat`-এর এই লাইনটা বদলান:
```
set SUPPORT_PHONE=+880-1XXXXXXXXX
```
অথবা `config.py` ফাইলে `SUPPORT_PHONE` বদলান।

## ৫. ডেটাসেট (জ্ঞান) কীভাবে বদলাবেন বা বাড়াবেন

সব জ্ঞান `tools/build_dataset.py` ফাইলে লেখা। এটাই মূল ফাইল।

- **উত্তর বদলাতে:** সংশ্লিষ্ট প্রশ্নের `"answer"` লাইন বদলান।
- **একই প্রশ্নের আরও রকমফের যোগ করতে:** ফাইলের মাঝামাঝি `EXTRA_CORES` অংশে ওই প্রশ্নের নিচে নতুন লাইন যোগ করুন।
- **নতুন প্রশ্ন যোগ করতে:** `INTENTS` লিস্টে একটা ব্লক কপি করে নতুন `"id"`, `"question"`, `"answer"` ও `"cores"` দিন।

তারপর চালান:
```
python tools/build_dataset.py
```
এটা `data/knowledge.json` নতুন করে বানায়, আর কোনো প্রশ্নের ৫০টির কম রকমফের থাকলে থেমে গিয়ে জানিয়ে দেয়।
সার্ভার আবার চালু করলে নতুন জ্ঞান কাজ করবে।

বটের ডেটাসেটে এখন যা আছে: AI Scooty কী, ফাউন্ডার (Md Rasel), ফাউন্ডারের জন্ম ও আদি দেশ, বাংলাদেশে একমাত্র কাজ করার অধিকার (পেপার),
সোলার/বিদ্যুৎ ছাড়া চলা, আবহাওয়া খারাপ হলে কারেন্টে চার্জ, এক স্কুটি থেকে আরেক স্কুটিতে চার্জ শেয়ার, বৃষ্টিতে চলা,
দাম (২ লাখ টাকা), কেনার নিয়ম, ব্যাংক ড্রাফট (১,২০,০০০ টাকা), ঢাকা সিটি, ট্রেড লাইসেন্স, NID ও অন্য কাগজপত্র,
কাস্টমার সাপোর্ট, বট কে, বট কী পারে, ভাষা, এবং Hello / Thanks / Bye।

## ৬. ভুল উত্তর কীভাবে আটকানো হয়েছে

ছোট মডেল (0.6B) সহজেই ভুল করে, তাই সিদ্ধান্তের কাজ মডেলকে দেওয়া হয়নি:

1. **কোন প্রশ্ন, সেটা ঠিক করে সাধারণ কোড** (`app/matcher.py`): ডেটাসেটের ৫০+ রকমফের মিলিয়ে দেখে, বানান ভুলও ধরে।
2. **নিশ্চিত হলে** উত্তর দেয়। **দ্বিধায় থাকলে** জিজ্ঞেস করে "Did you mean ...?" (বাটনসহ)। **কিছু না মিললে** সাপোর্টের নম্বর দেয়।
3. অচেনা শব্দ থাকলে (যেমন "price of iPhone") কখনো সরাসরি উত্তর দেয় না।
4. **Ollama মডেল শুধু শব্দ সাজায়।** ও গ্রাহকের আসল মেসেজ দেখেই না, শুধু নির্ধারিত প্রশ্ন ও নির্ধারিত তথ্য পায় (`app/llm.py`)। তাই jailbreak কাজ করে না।
5. মডেলের উত্তরে নতুন সংখ্যা/তথ্য ঢুকলে বা জরুরি শব্দ বাদ পড়লে কোড সেটা ফেলে দিয়ে লেখা উত্তর দেখায়।

AI-র শব্দ সাজানো বন্ধ করতে চাইলে `USE_LLM=false` সেট করুন (তখন সবসময় লেখা উত্তর)।

## ৭. টেস্ট

```
python tests/test_matcher.py
```
সঠিক প্রশ্নে সঠিক উত্তর যাচ্ছে কি না এবং অপ্রাসঙ্গিক প্রশ্ন (আবহাওয়া, কোডিং, ব্যাটারি/ওয়ারেন্টি ইত্যাদি, যা ডেটাসেটে নেই) আটকানো হচ্ছে কি না, দেখায়।
ডেটাসেট বদলালে আবার চালিয়ে নিন।

`http://127.0.0.1:8000/api/health` খুললে দেখা যাবে Ollama চালু আছে কি না ও মডেল ইনস্টল আছে কি না।

## ৮. সেটিংস (`config.py` বা environment variable)

| নাম | মানে | ডিফল্ট |
|---|---|---|
| `SUPPORT_PHONE` | কাস্টমার সাপোর্টের নম্বর | `+880-XXXX-XXXXXX` |
| `OLLAMA_MODEL` | কোন মডেল | `qwen3:0.6b` |
| `OLLAMA_URL` | Ollama-র ঠিকানা | `http://localhost:11434` |
| `USE_LLM` | AI দিয়ে শব্দ সাজানো | `true` |
| `PORT` | কোন পোর্টে চলবে | `8000` |

## ৯. ফোল্ডার

```
ai-scooty-chatbot/
  run.py  start.bat  start.sh  config.py  requirements.txt
  app/        main.py (সার্ভার)  matcher.py (প্রশ্ন চেনা)  llm.py (Ollama)  text_utils.py
  data/       knowledge.json  (build_dataset.py বানায়)
  tools/      build_dataset.py  (জ্ঞান এখানে লেখা)
  static/     index.html  style.css  app.js  (Windows-স্টাইল UI)
  tests/      test_matcher.py
```

## ১০. সমস্যা হলে

- **Ollama না চললেও** বট চলে, শুধু লেখা উত্তর দেখায়। AI-র সাজানো উত্তর চাইলে Ollama চালু রাখুন।
- **প্রথম উত্তর একটু দেরিতে** আসতে পারে (মডেল মেমোরিতে লোড হয়)। সার্ভার চালু হলে নিজে থেকেই লোড শুরু করে।
- **পোর্ট ব্যস্ত** বললে `PORT=8001` দিয়ে চালান।
- **চ্যাট মুছতে** উইন্ডোর উপরের ট্র্যাশ আইকনে ক্লিক করুন।

## ১১. পরের ভার্সনের জন্য

ডেটাবেস ইন্টিগ্রেশন (`KnowledgeBase` ক্লাস বদলালেই হবে), বাংলা ভাষা, ফাইন-টিউনিং। এখন বাংলায় লিখলে বট জানায় যে আপাতত শুধু ইংরেজি চলে।
