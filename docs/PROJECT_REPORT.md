## ১. সারসংক্ষেপ

AI Scooty Assistant হলো AI Scooty-র জন্য বানানো একটি ইন্টারনাল FAQ চ্যাটবট। ব্যবহারকারী Windows 11 স্টাইলের একটি চ্যাট উইন্ডোতে প্রশ্ন লেখেন, আর বট `data/knowledge.json` ফাইলে থাকা যাচাই করা তথ্য থেকে উত্তর দেয়।

প্রজেক্টের মূল সিদ্ধান্ত একটাই: **"সিদ্ধান্ত নেয় কোড, AI শুধু শব্দ সাজায়।"** ছোট AI মডেল (0.6B) সহজেই ভুল করে বা তথ্য বানিয়ে ফেলে। তাই কোন প্রশ্নের কী উত্তর যাবে, সেই সিদ্ধান্ত মডেলকে দেওয়া হয়নি।

এই ভার্সনে কোনো ডেটাবেস নেই। সব জ্ঞান একটি JSON ফাইলে থাকে।

## ২. সমস্যা ও উদ্দেশ্য

**সমস্যা**
- AI Scooty সম্পর্কে একই ধরনের প্রশ্ন বারবার আসে: এটা কী, দাম কত, কীভাবে কেনা যায়, কোন কাগজপত্র লাগে, চার্জ কীভাবে হয়।
- ছোট AI মডেল নিজে থেকে উত্তর দিলে ভুল বা বানানো তথ্য দিতে পারে।

**উদ্দেশ্য**
- শুধু যাচাই করা তথ্য থেকে উত্তর দেওয়া।
- নিশ্চিত না হলে কাস্টমার সাপোর্টের নম্বর দেওয়া, কখনো অনুমানে উত্তর না দেওয়া।
- AI (Ollama) বন্ধ থাকলেও বট চালু থাকা।

## ৫. ভুল উত্তর আটকানোর ব্যবস্থা

1. **কোন প্রশ্ন, সেটা ঠিক করে সাধারণ কোড।** ডেটাসেটের ৫০+ রকমফের মিলিয়ে দেখে, বানান ভুলও ধরে।
2. **তিনটি ফলাফলই সম্ভব।** নিশ্চিত হলে উত্তর, দ্বিধায় থাকলে "Did you mean ...?", কিছু না মিললে সাপোর্টের নম্বর।
3. **অচেনা শব্দে সরাসরি উত্তর নয়।** যেমন "price of iPhone" লিখলে বট কখনো সরাসরি উত্তর দেয় না।
4. **মডেল ব্যবহারকারীর আসল মেসেজ দেখেই না।** সে শুধু নির্ধারিত প্রশ্ন ও নির্ধারিত তথ্য পায়, তাই jailbreak কাজ করে না।
5. **মডেলের আউটপুট যাচাই।** উত্তরে নতুন সংখ্যা বা তথ্য ঢুকলে, বা জরুরি শব্দ বাদ পড়লে কোড সেটা ফেলে দিয়ে লেখা উত্তর দেখায়।

AI-র শব্দ সাজানো পুরোপুরি বন্ধ করতে চাইলে `USE_LLM=false` সেট করুন। তখন সবসময় লেখা উত্তর দেখানো হবে।

## ৬. ডেটাসেট (জ্ঞান)

সব জ্ঞান `tools/build_dataset.py` ফাইলে লেখা। এই ফাইল চালালে `data/knowledge.json` তৈরি হয়।

**বটের ডেটাসেটে যা আছে:**
AI Scooty কী, ফাউন্ডার, ফাউন্ডারের জন্ম ও আদি দেশ, বাংলাদেশে একমাত্র কাজ করার অধিকার (পেপার), সোলার/বিদ্যুৎ ছাড়া চলা, আবহাওয়া খারাপ হলে কারেন্টে চার্জ, এক স্কুটি থেকে আরেক স্কুটিতে চার্জ শেয়ার, বৃষ্টিতে চলা, দাম, কেনার নিয়ম, ব্যাংক ড্রাফট, ঢাকা সিটি, ট্রেড লাইসেন্স, NID ও অন্য কাগজপত্র, কাস্টমার সাপোর্ট, বট কে, বট কী পারে, ভাষা, এবং Hello / Thanks / Bye।

**জ্ঞান বদলানোর নিয়ম:**
- উত্তর বদলাতে: সংশ্লিষ্ট প্রশ্নের `"answer"` লাইন বদলান।
- একই প্রশ্নের আরও রকমফের যোগ করতে: `EXTRA_CORES` অংশে নতুন লাইন যোগ করুন।
- নতুন প্রশ্ন যোগ করতে: `INTENTS` লিস্টে একটা ব্লক কপি করে নতুন `"id"`, `"question"`, `"answer"` ও `"cores"` দিন।
- তারপর `python tools/build_dataset.py` চালান এবং সার্ভার আবার চালু করুন।

## ৯. চালানোর নিয়ম (Windows)

**যা লাগবে:** Python 3.13 (ইনস্টলের সময় "Add python.exe to PATH" টিক দিন) এবং Ollama।

1. প্রজেক্ট ফোল্ডারটা কম্পিউটারে রাখুন।
2. Command Prompt-এ একবার মডেল ডাউনলোড করুন:
   ```
   ollama pull qwen3:0.6b
   ```
3. `start.bat` ফাইলে দুবার ক্লিক করুন। প্রথমবার নিজে থেকেই সব ইনস্টল করে নেবে।
4. ব্রাউজারে খুলুন: **http://127.0.0.1:8000**

**হাতে হাতে চালাতে চাইলে:**
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python tools/build_dataset.py
python run.py
```

**PyCharm-এ:** ফোল্ডারটা Open করুন, interpreter হিসেবে Python 3.13 দিন, `requirements.txt` ইনস্টল করুন, তারপর `run.py` Run করুন।

## ১১. সেটিংস
